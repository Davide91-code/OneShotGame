#Progresso Progetto OneShotGame


[ Inserire qui il nome del gioco] è un gioco fantasy a turni single player.


Il giocatore assume il ruolo di un eroe che deve avanzare su un percorso di caselle
generate casualmente, affrontando eventi, nemici, segreti... 

Si vince raggiungendo l'ultima casella  e si perde se si esauriscono i punti vita.


API provate con Postman
Abbiamo verificato le chiamate per creare una partita, lanciare il dado e scegliere come affrontare un evento.

Contenuto del progetto
- Il backend, sviluppato in Java con Spring Boot, gestisce la partita, il lancio del dado, gli eventi e i punti vita.
- Il database MySQL salva i dati delle partite, dei giocatori e dei loro progressi.
- Il frontend, realizzato con HTML, CSS e JavaScript, mostra il gioco nel browser e permette di giocare.
- Il frontend comunica con il backend tramite le API. È disponibile anche una modalità demo offline.
